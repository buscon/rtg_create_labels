# Audio files

Put the 10 study clips and the 3 practice clips here, with the file names listed in `private/data/elements.csv` and `private/config.ini`.

For testing, create placeholders with `python scripts/make_placeholder_audio.py`.
The headphone-check stimuli go to `headphone/` (`python scripts/make_headphone_stimuli.py`).

Audio files are not stored in git.
