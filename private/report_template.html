2 Checks: real person or script?

Each check only marks a session for a closer look, it is not a verdict. The server already refuses answers before all three clips have been played to the end (at least 90 % of their length by the server clock), limits new sessions per IP address and requires a group code. Checks here: answer time compared with the listening time; listening time measured by the server; browser string; generic, repeated, very long or sentence-like labels; labels identical to another session; a random-looking device model; a very short session; no demographic answer (weak).
